## 十、已知问题与风险清单（代码审计结论）

| # | 级别 | 问题 | 说明 / 建议 |
|---|---|---|---|
| 1 | ⚠️ 偏差 | **自动保存与 PRD L1 不符** | PRD L1 要求「实时自动保存 + 崩溃恢复」；当前是按你此前拍板改为**手动 Ctrl+S + 草稿恢复**（草稿仅在保存成功时写入）。功能可用，但与红线字面不符——若需严格达标需恢复实时保存，**请确认取舍** |
| 2 | ⚠️ 文案 | 「专注」按钮 title 仍写"隐藏工具栏" | `index.html` 里 `btn-focus` 的悬浮提示是"专注模式(隐藏工具栏)"，与现行为（保留工具栏）不符，建议改文案 |
| 3 | ⚠️ 实测 | 大文档（11.6M 字符级）端到端流畅度 | 已做增量渲染 + 超大降级源码模式优化，但**需用真实超大文档实测**输入/预览/滚动无卡顿（此前卡顿根因已修，回归验证） |
| 4 | ⚠️ 实测 | Mermaid 思维导图（mindmap） | 流程图/时序图/甘特图确认支持；**mindmap 需实测**，若打包的 mermaid 版本不支持需升级 mermaid 或提示用户 |
| 5 | ⚠️ 实测 | PDF 导出大文档 | 此前修过 data URL 超长 ERR_INVALID_URL（改走临时文件），**含多图大文档导出 PDF 需回归验证** |
| 6 | ℹ️ 提示 | 富文本 ↔ 源码切换的格式漂移 | 依赖 turndown 序列化，**嵌套表格/自定义 HTML 极端排版**可能轻微漂移，常见 Markdown 无影响 |
| 7 | ℹ️ 提示 | 源码模式粘贴 base64 图片不实时折叠 | 只在 setValue/加载文件时折叠，源码模式直接粘贴大段 base64 会撑爆编辑区（可切富文本粘贴或后续加实时折叠） |
